# Official ECO logo – required

Place the **official ECO Mobility logo file supplied by ECO** here as:

    public/brand/eco-logo.png

The application never draws, recreates or edits the logo. It only scales it proportionally and applies
transparency for the subtle background watermark. Until this file exists, DP generation is disabled and the
app shows "Setup pending".

Optional: if the ECO brand team can provide a transparent-background version of the logo (red mark on
transparent), save it as `eco-logo-watermark.png`. It will be used for the watermark instead of the
red-square version and looks cleaner on the white DP background.
